Waving flag artwork exported from Noto Color Emoji v2.047 (Google Inc.), the
font the design renders these flags with. Each file is the emoji glyph for the
country's regional-indicator pair, cropped to its own bounds at the font's
native 136px bitmap size, then colour-quantised.

Noto Color Emoji is licensed under the SIL Open Font License 1.1
(http://scripts.sil.org/OFL). These are rendered images, not font software.

They exist because Windows cannot draw flag emoji at all, and macOS draws a
different flag. The flat rectangular flags one directory up are a separate set,
used for the circular chips on the destination cards and in the course finder.
